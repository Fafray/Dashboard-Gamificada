# Resumo — Análise

## O que esta pasta cobre
Métricas de uso, performance do app e análise de padrões de hábitos ao longo do tempo.

## Quando consultar esta pasta
Quando quiser avaliar o que está funcionando — hábitos com melhor aderência, features mais usadas, padrões de comportamento.

## Mapa de arquivos
*(Vazio — pasta criada para crescer quando o app estiver em uso real)*

## Conexões com outras pastas
| Se o contexto for... | Consulte também... | Motivo |
|----------------------|--------------------|--------|
| Feature de histórico/resumo | `features/` | Specs definem o que é coletado e exibido |
| Schema de dados | `tecnico/banco-de-dados.md` | Fonte dos dados para análise |
| O que otimizar | `produto/roadmap.md` | Análise informa prioridades |

## Quando criar novo arquivo aqui
Quando o app estiver sendo usado e houver dados reais para analisar. Exemplos futuros:
- `metricas-uso.md` — quais hábitos têm mais check-ins, quais são abandonados
- `padroes-semana.md` — em quais dias da semana a aderência cai
- `retencao.md` — o usuário está usando o app com que frequência
