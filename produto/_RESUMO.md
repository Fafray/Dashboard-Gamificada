# Resumo — Produto

## O que esta pasta cobre
Visão do produto, direção estratégica e roadmap de features.

## Quando consultar esta pasta
Quando a pergunta for "o que construir agora?" ou "isso faz sentido para o produto?".

## Mapa de arquivos
| Arquivo | Quando usar | Sinal de busca |
|---------|-------------|----------------|
| `visao.md` | Decisões de direção, escopo, identidade do app | propósito, diferencial, horizonte, mobile |
| `roadmap.md` | Priorização, sequência de implementação | fase, próximo, ordem, quando |

## Conexões com outras pastas
| Se o contexto for... | Consulte também... | Motivo |
|----------------------|--------------------|--------|
| Especificar como a feature funciona | `features/` | Roadmap define o quê, features define o como |
| Decisão de UI para a feature | `ux/` | Visão define o tom, UX define a forma |
| Impacto no banco de dados | `tecnico/banco-de-dados.md` | Cada feature nova pode mudar o schema |

## Quando criar novo arquivo aqui
Quando surgir um tema estratégico que não é uma feature específica: expansão para múltiplos usuários, monetização, parcerias, decisão de plataforma mobile.
