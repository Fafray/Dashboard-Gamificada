# Visão do Produto

## O que é o Daily Quest
Dashboard gamificada de hábitos pessoais. O usuário registra atividades do dia a dia, ganha XP, sobe de nível, mantém streaks e desbloqueia conquistas. A lógica de RPG cria motivação intrínseca para manter os hábitos.

## Para quem é (agora)
Uso pessoal do criador. Um usuário, uma rotina.

## O que o diferencia
Não é um app de produtividade frio. É um sistema de progressão. O feedback visual — XP animado, streaks com chama, conquistas desbloqueando — torna o ato de registrar um hábito satisfatório por si só.

## Horizonte de evolução
1. **Imediato:** app configurado para a rotina real, sendo usado todos os dias
2. **Curto prazo:** features que faltam (rastreio numérico, Nx/semana, resumo mensal)
3. **Médio prazo:** mais interativo, mais atrativo — reduzir atrito, aumentar recompensa
4. **Longo prazo:** app mobile

## O que não é
- Não é um app social (por enquanto)
- Não é um to-do list
- Não é um tracker de saúde — mas pode se aproximar disso com rastreio numérico
