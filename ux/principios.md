# Princípios de UX — Daily Quest

## Filosofia central
O app deve fazer o usuário **querer** abrir — não sentir que precisa. A diferença está no feedback: cada interação deve ser satisfatória por si só, não só instrumentalmente útil.

## Princípios

### 1. Feedback imediato e rico
Cada check-in deve parecer uma recompensa. XP animado, pulse ring, streak flame — o ato de marcar deve ser prazeroso independente do hábito em si.

### 2. Progresso sempre visível
Nível, XP atual, streaks — visíveis em menos de 3 segundos após abrir o app. O usuário deve sentir que está avançando.

### 3. Fricção mínima
Check-in deve ser um toque. Qualquer fluxo com mais de 2 passos precisa de justificativa forte. Input numérico (rastreio de água, sono) é a exceção aceitável — vale a riqueza dos dados.

### 4. Gamificação honesta
XP e conquistas devem refletir esforço real. Inflar números ou dar XP fácil destrói a credibilidade do sistema — o usuário para de se importar com o número.

### 5. Identidade visual consistente
Design system definido: tokens CSS Aurora, Space Grotesk + Manrope, tema dark/light. Toda nova feature deve usar as classes e tokens existentes — não criar estilos fora do sistema.

## Tensões a monitorar
- **Riqueza de dados vs. fricção:** input numérico adiciona valor mas aumenta o atrito do check-in
- **Gamificação vs. honestidade:** mais recompensas engajam, mas desvirtuar o sistema vai contra o propósito

## O que ainda não foi resolvido
- O que faria o usuário abrir o app todos os dias mesmo sem ter hábitos para marcar?
- Notificações / lembretes — quando e como?
- Celebrações mais impactantes no level-up e conquistas
- Onboarding: como guiar alguém novo a configurar seus primeiros hábitos
